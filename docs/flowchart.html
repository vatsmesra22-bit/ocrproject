CSP link kholta hai (phone / laptop)
▼
1. Login - apni CSP ID se
▼
2. Upload - list ki photo ya Excel file
▼
Photo saaf hai?
Nahi → "saaf photo lo" → dobara upload
Excel hai?
Seedha padh liya, OCR nahi chahiye
▼
3. OCR - list padhna
Pehle Voxomos (internet)  →  fail ho to RapidOCR (laptop/server par, bina internet)
▼
4. Sirf 3 cheezein rakho: Account + Naam + Mobile
baaki sab (gaon, pata, pita ka naam) aur photo - server bhool jaata hai; list sirf CSP ke phone mein
▼
5. Har row ka check
✓ OK ⚠ Galti - naam/number galat, duplicate ☎ Mobile nahi - call / visit
▼
6. CSP paper se milata hai → galti theek → tick → Save
▼
7. WhatsApp - har customer ke aage button → tap → Send
(Hindi + English message, CSP ke apne WhatsApp se)
▼
8. CSP ka phone (list yahin rehti hai)
7 din baad reminder  •  "Aaya" mark  •  STOP = kabhi message nahi  •  admin report  •  30 din baad phone se delete

🔒 DPDP (data suraksha)

  • Sirf account, naam, mobile
  • List server par kabhi save nahi - sirf CSP ke phone mein (30 din)
  • Har CSP ko sirf apni list
  • Log mein customer data nahi
  • Voxomos asli list ke liye tabhi: saving band + India server + agreement + naya key
  • App ke andar koi AI (Claude) nahi

📍 Kahan chalta hai

  • Abhi: laptop par (127.0.0.1:8000)
  • Aage: India server par HTTPS link - CSP phone se kholega

👤 Kaun kya kar sakta hai

  • CSP: apni list upload, check, send
  • Super admin: CSP banana, password reset, report
